How to capture:

Enter each command in your console.

When the full output appears, use GNS3’s “Take Screenshot” (or identical) of only the console window.

Label each image “REQ3‑Device‑Command” (e.g. REQ3‑EXEC‑PingLANA).

Once you’ve collected all 10–12 screenshots above, you’ll have clear evidence that:

The CE ↔ CE link is up.

Both R&D subnets are reachable.

Only LAN A traffic is carried over IPSec (QM_IDLE + packet counters), LAN B is not.

That completes Requirement 3.
