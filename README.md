# **Enterprise MPLS VPN \& Network Security Project**



This project demonstrates the design and implementation of a secure enterprise WAN infrastructure using MPLS VPN, IPSec, OSPF, DHCP, and access control technologies in Cisco GNS3 environments.



The network was designed to support secure communication between multiple company branches while ensuring:

\- Secure department communication

\- MPLS VPN segmentation

\- IPSec encrypted tunnels

\- DHCP-based IP management

\- ACL-based traffic restrictions

\- SQL server access security

\- Efficient IP addressing



The project includes:

\- Cisco router configurations

\- MPLS VPN implementation

\- IPSec site-to-site security

\- Network testing \& troubleshooting

\- Performance-based design decisions
